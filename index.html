🔑 연결 — GitHub 발행 연결(소유자 전용). 내 휴가를 저장소에 자동 발행해 다른 사람이 읽기 전용으로 볼 수 있게 합니다. 토큰은 이 브라우저에만 저장됩니다.
🌙 — 주간/야간 테마 전환
📤 백업 — 휴가·보유량을 JSON 파일로 저장 (기기 이전·주소 변경 시)
📥 복구 — 백업 파일을 읽어 현재 데이터를 덮어씀
내 조 1/2/3/4 — 메인 캘린더의 근무 패턴 조. 휴가 데이터는 조와 무관하게 유지되고, 다른 조를 보면 내 휴가 위치에 빨간 상자만 표시됩니다.
👥 전체 조 탭 — 모든 조의 근무를 칩(예: 3B = 3조 저녁)으로 하루에 파악

휴가 종류
· 연차 — 근무연도(12월 마감 기준)에서 차감
· 연중 — 연중 휴가, 달력연도 기준
· 교대케어 — A·B조 근무일만 사용 가능
· 야간케어 — C조 근무일만 사용 가능
· 특근제외 — 공휴일에만, 차감 없음

기타 입력
· 연장(OT)/조출 — 근무 시간 기록
· 교육 — 교육 이수 시간 기록
· 메모 — 단순 메모, 집계·상자와 무관

캘린더 표시
· A 낮 07–15 · B 저녁 15–23 · C 밤 23–07 · 휴 휴무
· 빨간 글씨 날짜 — 공휴일 / 주황 글씨 — 대체공휴일
· n월분 시작/마감 — 급여 기준월 경계 (15일 당일/직전 일요일 마감)
· 💰 급여 — 급여일 (25일이 휴일이면 앞 평일)
· 연차 마감 — 이 해 연차를 쓸 수 있는 마지막 날
· 빨간 상자 — 이어지는 휴무/휴가 구간
· 📝 — 단순 메모
